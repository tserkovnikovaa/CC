# Анкета перед карьерной консультацией

Интерактивная анкета для клиентов Анастасии Церковниковой, размещаемая через GitHub Pages.

- Трехшаговая форма с проверкой обязательных ответов.
- Интеграция с Formspree: `https://formspree.io/f/moedpdzq`.
- Бесплатный тариф Formspree: вместо прикрепления файла предусмотрено необязательное поле со ссылкой на актуальное резюме.
- Ссылки на политику обработки персональных данных и согласие включены в форму.
- GitHub содержит только исходный код страницы, а не ответы клиентов.

## Как опубликовать сайт

В GitHub откройте **Settings → Pages**, в **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем **Save**.

Ожидаемая ссылка сайта после публикации:
https://tserkovnikovaa.github.io/-areer/

## Как проверить отправку

1. Убедитесь, что в панели Formspree для формы `moedpdzq` выбран правильный email получателя и подтвержден адрес, если сервис этого требует.
2. Откройте опубликованную страницу и заполните тестовую анкету **вымышленными** данными.
3. Проверьте появление обращения в Formspree и уведомления на email (включая спам).
4. Если письма не приходят, проверьте настройки **Notifications** в Formspree.

## Перед приемом данных клиентов

Анкета передает данные на серверы Formspree. Для обработки персональных данных граждан РФ необходимо отдельно проверить соблюдение применимых требований к локализации, трансграничной передаче данных и действительность согласия на соответствующую обработку. Не используйте реальные данные до завершения такой проверки.
